# Spoke Networks

- **Prod:** `vnet-prod-eastus` (10.1.0.0/16) with three-tier subnets (web, app, db).
- **Dev:** `vnet-dev-eastus` (10.2.0.0/16) with a single subnet for flexibility.

Each subnet is `/24` for clear separation and future NSG/route table assignments.
